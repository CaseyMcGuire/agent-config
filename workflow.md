# Shared workflow

## Scope

- Implement only the requested work, including necessary supporting changes.
- Earlier discussions provide context, not authorization to build additional features.

## Skills

- Review both native installed skills and the [shared skill catalog](./AGENTS.md#skill-catalog).
  Follow the catalog's loading rules to read skills relevant to the task or
  requested by name, including those available only through a URL.

## Git workflow

- Commit and push only when requested.
- Follow the project's branch conventions.
- When stacked PRs are requested, create them incrementally, with each PR targeting the preceding branch and containing one reviewable stage.
